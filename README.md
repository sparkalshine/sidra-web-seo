# Sidra Portfolio

Professional portfolio website for **Sidra — Website Developer, SEO Content Writer & 100% Human Copywriter**.

## Files
- `index.html` — website structure and content
- `style.css` — responsive design and animations
- `script.js` — menu, scroll progress and reveal animations

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Repository → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main** → Folder: **/ (root)** → Save.

### Before publishing
Replace `hello@example.com` in `index.html` with your real email address and replace the sample portfolio cards with your actual work.
